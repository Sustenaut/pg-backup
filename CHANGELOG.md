## 0.2.1 - 2026-11-08

Commit `509ef3c5dbe4`; release record `pub:sha2-256:x447fzgq3nepl7utzpct5spztlm43nw6cvviyy5q5clucsk55dkq`.

### Added

- pg-backup --version prints the installed release's version (0.2.0 said 0.1.0), and consumer/pg-backup pins the release it ships in

## 0.2.0 - 2026-11-07

Commit `5c558e216a76`; release record `pub:sha2-256:v6gitgtniatqqiwjea3xee7ohatdm7vnjhmgzcf5gdvbd4uoxsya`.

### Changed
- drill says DRILL NOT RUN (exit 2), not DRILL FAILED, while the database isn't on pg-backup's image yet, and shows people's times in the machine's own zone, with the zone named

### Added
- drill --wait: right after a merge, waits for the StatefulSet's rollout and for a base backup old enough, then drills

### Fixed
- restore and drill: a database nobody wrote to since the moment can be restored to it (pg-backup closes a WAL segment on live first, so the archive covers it), and a restore whose PostgreSQL stopped fails at once with the end of its log instead of waiting 30 minutes
